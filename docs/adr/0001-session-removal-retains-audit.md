# ADR 0001：移除会话保留审计与用量数据

- 状态：已接受
- 日期：2026-07-22

## 决策

“移除会话”采用软删除：会话从 UCLI 工作台列表隐藏，运行中的 CLI 进程被停止，但数据库中的会话元数据、token、费用、轮次、审批统计和按模型统计继续保留。UCLI 不删除 AI CLI 的源会话。

“关闭窗格”与“停止会话”是不同操作：关闭只影响当前 UI 窗格；停止还会结束 CLI 进程，但会话仍可恢复。

## 原因

token 与费用是用户已经实际发生的成本，审批记录也是安全审计的一部分。工作台整理行为不能改写历史用量。

## 实现约束

- 保持现有 `session:delete` IPC 名称，以兼容已发布的 renderer/preload 接口；其业务语义改为“移除”。
- `sessions.removed_at` 标记软删除。
- 普通会话列表排除已移除记录；统计查询包含已移除记录。
