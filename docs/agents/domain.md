# Domain docs

UCLI uses a single domain context.

Before changing or testing behavior, read the root `CONTEXT.md` and the ADRs in `docs/adr/` relevant to the affected area.

Use the domain vocabulary defined there, especially source session, workbench session, close pane, stop session, remove session, source provider, and safety-rule mode. If a proposed change conflicts with an ADR, call that out explicitly instead of silently changing the decision.
