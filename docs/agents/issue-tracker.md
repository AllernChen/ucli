# Issue tracker: GitHub

Issues, release regressions, and follow-up work for UCLI are tracked in this repository's GitHub Issues.

## Conventions

- Create issues with the GitHub CLI when it is available, or through the repository's GitHub web UI.
- Include the UCLI version, Windows version, affected CLI/provider, reproduction steps, expected result, actual result, and relevant non-sensitive logs in defect reports.
- Link a regression issue to the release tag or Release page it affects.
- Close an issue only after the fix is verified against the stated reproduction steps.

## When a workflow says "publish to the issue tracker"

Create a GitHub Issue in `AllernChen/ucli`.
