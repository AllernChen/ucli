结论依据

  • 已验证通过：提交 5271360 上 fresh npm test 共 1209 项，1199 通过、10 项平台跳过、0 失败；npm run build 成功。
  • 已验证通过：npm audit --registry=https://registry.npmjs.org --json 检查 533 个依赖，漏洞总数为 0；整改前全量审计曾报告 20 个漏洞，已通过显式升级和精确 override 消除。

Q-001 发布依赖漏洞与工具链兼容

已确认事实

  • 整改前官方源生产审计包含 adm-zip、nanoid、postcss、smol-toml 风险；全量审计合计 20 个漏洞，其中含 critical/high。
  • 升级 Electron、electron-builder、Vite、TOML/ZIP 依赖后，builder 26 不再接受旧 win.sign: false，并且内存受限环境中的 PNG 转 ICO 转换失败。
  • smol-toml 1.8 的格式化变化会破坏 Codex profile byte-exact fixture。

根因判断

  • 根因状态：已确认。
  • 根因是旧发布工具链和未固定的传递依赖基线滞后，同时缺少 Windows icon/sign 配置的回归契约。

位置与证据

  • 文件：package.json、package-lock.json、electron-builder.yml、build/icon.ico、electron/aiCliProfiles/codexProfileFile.js、test/release-workflow.test.mjs。
  • 复现：整改前运行官方 npm audit；升级后运行 Codex profile focused tests 和 Windows builder。
  • 证据：初始审计 20 漏洞；TOML fixture 2 项 RED；builder schema 和 PNG 转换各一次 RED；最终全量审计 0、测试/构建/Windows 打包 GREEN。

影响与风险

  • 发生条件：解析恶意 ZIP/受影响依赖路径，或在干净发布机执行旧配置。
  • 业务影响：潜在拒绝服务/依赖漏洞暴露；Windows 发布失败或图标缺失；Codex 档案产生无关字节漂移。
  • 数据或安全影响：整改前存在供应链与输入处理风险；未发现已利用证据。
  • 可恢复性：通过显式升级、精确 override、配置迁移和兼容 serializer 恢复。

整改与复测

  • 临时止血：无；直接完成根因修复。
  • 永久修复：Node 24 CI；Electron 43 / builder 26 / Vite 7；精确安全 override；提交预生成 ICO；Codex TOML 边界兼容；发布配置契约测试。
  • 回归用例：全量测试 1209 项；release workflow 6/6；Codex ZIP/TOML focused 25/25；官方 audit、build、dist:win、verify:release。
  • 残余风险：锁文件仍含 45 个历史 registry.npmmirror.com URL，本次未引入；建议后续独立规范化，避免把大规模锁文件来源变更混入当前发布。
  • 责任人和期限：维护团队；已于提交 5271360 关闭。
