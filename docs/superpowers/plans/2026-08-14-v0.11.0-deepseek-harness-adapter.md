# UCLI 0.11.0 DeepSeek Harness TUI Bridge Upgrade Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 UCLI 0.11.0 中把 DeepSeek Harness 作为第五种 AI CLI 接入：优先承载用户已经安装的兼容 DSH TUI profile，并用 UCLI 自带的 DSH bridge plugin 恢复权限、统计、通知和 Gateway 语义；当兼容 TUI 或 bridge 不可用时，提供受限但可用的官方本地 Web 回退。

**Architecture:** 采用“PTY 数据面 + 插件语义面”的双平面结构。UCLI 的 xterm 通过 `node-pty` 直接承载 `dsh --profile <name>`，不解析 ANSI/TUI 输出；随 UCLI 分发的 `@ucli/dsh-bridge` 插件通过一次性认证的本地 IPC，把 DSH agent/session/tool 事件与控制 RPC 映射到 UCLI。Web 回退独立启动 `dsh web --host 127.0.0.1 --port 0`，其权限、历史和统计仍归 DSH 原生界面所有。

**Tech Stack:** Electron 32, Node.js ESM, Vue 3, Pinia, Ant Design Vue, `node-pty`, `node:net`, SQL.js, node:test, electron-vite, electron-builder, pnpm CLI, `@deepseek-ai/dsh@0.1.0-rc.6`.

## Global Constraints

- 目标版本固定为 UCLI `0.11.0`；现有 `0.10.2` 数据库、会话、布局、AI CLI profile、规则、Skills、统计、总结和 Gateway 路由必须无损升级。
- 可安装运行基线固定为 npm 发布物 `@deepseek-ai/dsh@0.1.0-rc.6`（registry tarball SHA-1 `de9fbf39056c7f4e658a3e284cb1d66ebc86d040`）。该发布物不含 `gitHead`；仓库提交 `47f943859bef60e4160492346772ded9b24f765a` 仅作为相邻架构资料，不再充当可安装版本标识。其他 DSH 版本显示为不兼容，不得静默启动。
- `deepseek-ai/deepseek-harness` 主仓库不包含可直接运行的人类 TUI 客户端源码或 bundle；官方文档所指向的 `deepseek-harness/turtle-ui` 在本方案制定时不可获取。因此 0.11.0 只适配用户已经安装的兼容 TUI profile，不下载、不镜像、不承诺安装 `turtle-ui`。
- UCLI 只在用户对明确选中的 profile 执行“启用 UCLI 集成”时安装或更新 bridge；应用启动、CLI 探测和普通 TUI 启动不得修改 `~/.dsh`。
- bridge 安装通过官方 `dsh plugin --profile <name> add <bundled-tgz>` 完成。执行前只备份该 profile 的 `package.json`、`pnpm-lock.yaml`、`pnpm-workspace.yaml`、`cordis.patch.yml`；失败时恢复这些元数据，绝不删除 profile、TUI bundle、用户插件、凭据或 DSH 历史。
- PTY 平面只传递终端字节、resize 和进程生命周期。不得从 ANSI、屏幕文本、OSC 序列或 TUI stdout 推断 session、tool、usage、permission、plan 或 result。
- bridge 不向 TUI stdout 写 JSON、日志或诊断信息；语义消息只走认证本地 IPC。未连接 bridge 的 TUI 不得被标记为拥有 UCLI 权限、统计、通知或 Gateway 能力。
- Windows 使用 `\\.\pipe\ucli-dsh-<uuid>`；macOS 使用 `join(tmpdir(), 'ucli-dsh', '<uuid>.sock')`。macOS 父目录权限为 `0700`、socket 为 `0600`，清理前必须验证解析后的路径仍位于该精确临时子目录。
- 每次启动生成 32 字节随机十六进制 token。endpoint、token 和 protocol 只经 `UCLI_DSH_BRIDGE_ENDPOINT`、`UCLI_DSH_BRIDGE_TOKEN`、`UCLI_DSH_BRIDGE_PROTOCOL=1` 注入子进程；不得写入数据库、profile、日志、renderer IPC 或错误详情。
- bridge frame 使用 uint32 big-endian 长度前缀加 UTF-8 JSON，单帧上限 1 MiB。首帧必须在 10 秒内完成握手；token/协议不符、第二个客户端、非法 JSON、超限帧或意外断线都关闭连接并产生稳定错误码。
- bridge 权限钩子必须覆盖根 agent、subagent、Code Mode 子调用和所有 model-facing tools。断线、卸载、取消或响应超时一律返回 deny；未通过端到端覆盖验证前不得宣称 `permissionOwner: 'ucli'`。
- bridged TUI 的单次 tool ask 只能出现一个交互式决策入口。UCLI bridge 负责 ask/allow/deny，DSH sandbox 仍执行隔离；不得同时弹出 DSH 原生 ask 与 UCLI ask。
- Web 回退只允许固定参数 `dsh web --host 127.0.0.1 --port 0`，只接受严格的 `http://127.0.0.1:<port>` readiness URL。不得绑定 LAN、接受 renderer 传入的 host/port/命令或持久化临时 URL。
- Web 回退能力固定为 DSH 原生权限、历史和统计，并禁用 Gateway；不以抓取 iframe、读取 DSH 文件或解析进程输出的方式伪造 bridge 能力。
- DSH 保持默认 `~/.dsh` 或用户已有 `DSH_HOME`。UCLI 不复制、读取、记录或删除 provider 凭据、原生 transcript、插件数据和历史。
- 数据库只保存 allowlist 后的 `{ profileName, surfacePreference }`；不得保存 endpoint、token、Web URL、DSH home、凭据、命令或任意额外参数。
- 每项生产改动遵循 RED → GREEN → REFACTOR；每个任务以独立 scoped commit 结束。发布结论必须来自新鲜的自动化、构建、打包和平台手工验收证据。

- [CLI reference](https://github.com/deepseek-ai/deepseek-harness/blob/master/apps/cli/reference/README.zh.md) 给出 `dsh plugin --profile <profile> add <bundle>`、`--resume`、`web`、`--host` 和 `--port` 等正式命令。
- [Architecture](https://github.com/deepseek-ai/deepseek-harness/blob/master/docs/architecture.zh.md) 说明 DSH 的 session event 是持久事件、agent event 是实时事件，功能通过插件扩展。
- [Tools subsystem](https://github.com/deepseek-ai/deepseek-harness/blob/master/docs/subsystems/tools.zh.md) 定义 `tools/pre-execute` waterfall hook 和 allow/deny/ask 决策。
- [Agent/core subsystem](https://github.com/deepseek-ai/deepseek-harness/blob/master/docs/subsystems/core.zh.md) 提供 agent 列举、followup、cancel、状态和生命周期接口。
- [Session subsystem](https://github.com/deepseek-ai/deepseek-harness/blob/master/docs/subsystems/session.zh.md) 定义 assistant、tool、turn、step 和 usage 事件。
- [Permission presets](https://github.com/deepseek-ai/deepseek-harness/blob/master/docs/subsystems/permission-presets.zh.md) 区分 `workspace-write` 与 `danger-full-access` sandbox。
- [Skills subsystem](https://github.com/deepseek-ai/deepseek-harness/blob/master/docs/subsystems/skills.zh.md) 说明项目级 `.agents/skills` 的扫描行为。
- [ACP limitations](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/acp/acp/README.zh.md) 仍缺少 UCLI 所需的完整 resume/history/tool/usage/plan 语义，因此 0.11.0 不选 ACP 作为主接入面。

结论是：DSH 确实支持 `pnpm dsh --profile tui` 这类 TUI profile，但 TUI 不是当前主仓库中的内置客户端。UCLI 0.11.0 不重写 TUI，也不等待不可获取的 `turtle-ui`；它承载现有 profile，并通过可审计的 bridge plugin 对接 UCLI 能力。

## Bridge Protocol v1

Transport frame is `uint32be(length) + JSON UTF-8 bytes`. The first frame is:

```json
{
  "type": "hello",
  "protocolVersion": 1,
  "token": "<64 lowercase hex characters>",
  "bridgeVersion": "0.11.0",
  "profileName": "tui",
  "surface": "tui",
  "capabilities": {
    "terminal": true,
    "resume": true,
    "permissions": true,
    "stats": true,
    "notifications": true,
    "gateway": true,
    "planSnapshot": true,
    "resultSnapshot": true
  }
}
```

UCLI returns `hello-ack` only after token, protocol, profile and capability validation. Event methods are:

- `session-ready { nativeSessionId, cwd, model }`
- `agent-status { nativeSessionId, status }`
- `assistant-committed { nativeSessionId, turnId, text }`
- `tool-request { requestId, nativeSessionId, tool, input, cwd, command }`
- `tool-result { requestId, nativeSessionId, status }`
- `usage { nativeSessionId, inputTokens, outputTokens, turns, model }`
- `turn-complete { nativeSessionId, turnId, status }`
- `attention { nativeSessionId, kind, operation }`
- `plan-snapshot { nativeSessionId, markdown }`
- `result-snapshot { nativeSessionId, markdown }`

Main-to-plugin control uses `{ type: 'request', requestId, method, params }` and a matching response. Supported methods are `turn.send`, `turn.interrupt`, `snapshot.plan`, and `snapshot.result`. Permission decisions use a separate plugin-to-main `permission.decide` request bound by the server to its UCLI session; cancellation aborts the matching request and late responses are ignored. `turn.send` and `turn.interrupt` resolve exactly one root agent for the native session；zero roots returns `DSH_ROOT_AGENT_NOT_FOUND`，multiple roots returns `DSH_ROOT_AGENT_AMBIGUOUS`，不得猜测目标。

```js
export const DSH_BRIDGE_PROTOCOL = 1
export const DSH_BRIDGE_MAX_FRAME_BYTES = 1024 * 1024
export const DSH_BRIDGE_HANDSHAKE_TIMEOUT_MS = 10_000

export function encodeBridgeFrame(value) {
  const body = Buffer.from(JSON.stringify(value), 'utf8')
  if (body.length > DSH_BRIDGE_MAX_FRAME_BYTES) throw bridgeError('DSH_BRIDGE_FRAME_TOO_LARGE')
  const header = Buffer.allocUnsafe(4)
  header.writeUInt32BE(body.length)
  return Buffer.concat([header, body])
}
```

ctx.on('tools/pre-execute', async function (exec, next) {
  const downstream = await next()
  if (downstream.kind === 'deny') return downstream
  const decision = await bridge.requestPermission(normalizeToolExecution(exec))
