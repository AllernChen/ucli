# UCLI 0.12.0 Model Protocol Capabilities Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade UCLI 0.12.0 to select and project server models only through explicit `protocols`, preserve credentials across stable Gateway 503 failures, and complete one protocol-aware live smoke.

**Architecture:** Extend the existing strict server contract boundary with public protocol parsing, Gateway directory parsing, fixed endpoint selection, and allowlisted failure diagnostics. Keep the loopback proxy transparent and non-replaying for POST requests; make the existing Codex/Claude projection filter models by each adapter's real wire protocol. The live smoke uses an explicitly configured `openai_responses` protocol, validates both model directories before sending a request, and emits only allowlisted evidence.

**Tech Stack:** Electron 43, Node.js 22 Web Fetch API, Node Test Runner, sql.js-backed profile projection, Markdown release documentation.

**Spec:** `docs/superpowers/specs/2026-08-29-ucli-0.12-model-protocol-capabilities-design.md`

## Global Constraints

- Client target version remains exactly `0.12.0`.
- Public model protocols are exactly `openai_responses`, `openai_chat`, and `anthropic_messages`.
- `gemini` is server-internal and must never become a client capability, configuration value, or native Gateway route.
- Missing, empty, or unknown `protocols` fail closed; do not add an old-server fallback or infer from model ID, vendor, display name, or `models[0]`.
- Codex consumes only `openai_responses`; Claude consumes only `anthropic_messages`.
- A model that only exposes `openai_chat` does not produce a managed profile in 0.12.0.
- Gateway model POST requests are never automatically replayed.
- Stable Gateway 503 failures never clear the current server connection or saved refresh token and never disable local models, local Skills, local data, or independent mode.
- Safe diagnostics contain only status, Content-Type, Cache-Control, stable code, request ID, and retryable.
- Never place a Connection URL, fragment, token, Authorization/Cookie value, response body, complete response headers, user identity, provider secret, or complete stack in source, fixtures, commands, logs, screenshots, commits, or handoff documents.
- Do not reuse the previous service baseline `28bdc40` / `sha256:ef15c26f8d80` unless the server owner explicitly confirms that the new deployment uses it.
- The live smoke consumes one new authorization once and is not rerun across processes after Redeem.

```js
function parseModelProtocols(value) {

function parseGatewayModel(value) {

    ownedBy: requiredString(value.owned_by),
    displayName: requiredString(value.display_name),
    contextSize: value.context_size,

}
```

```js
export function parseGatewayModelsResponse(value) {
  value = object(value)
  if (value.object !== 'list' || !Array.isArray(value.data)) throw responseError()
  return { object: 'list', data: value.data.map(parseGatewayModel) }
}

export function selectModelForProtocol(models, protocol) {
  if (!Array.isArray(models) || !PUBLIC_MODEL_PROTOCOL_SET.has(protocol)) throw responseError()
  return models.find(model => Array.isArray(model?.protocols) && model.protocols.includes(protocol)) || null
}

export function localGatewayPathForProtocol(protocol) {
  const path = MODEL_PROTOCOL_LOCAL_PATHS[protocol]
  if (!path) throw responseError()
  return path
}
```

For directory agreement, compare protocol sets without assigning priority to array order:

```js
function sameProtocolSet(left, right) {
  return left.length === right.length && left.every(protocol => right.includes(protocol))
}

export function assertGatewayModelProtocolConsistency({ bootstrapModels, gatewayModels, modelId, protocol } = {}) {
  if (!PUBLIC_MODEL_PROTOCOL_SET.has(protocol)) throw responseError()
  const bootstrapModel = bootstrapModels?.find(model => model.id === modelId)
  const gatewayModel = gatewayModels?.find(model => model.id === modelId)
  if (!bootstrapModel || !gatewayModel ||
    !bootstrapModel.protocols.includes(protocol) || !gatewayModel.protocols.includes(protocol) ||
    !sameProtocolSet(bootstrapModel.protocols, gatewayModel.protocols)) {
    throw responseError()
  }
  return gatewayModel
}
```
