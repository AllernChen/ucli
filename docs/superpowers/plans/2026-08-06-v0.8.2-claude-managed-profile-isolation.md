# UCLI 0.8.2 Claude 托管档案隔离实施计划

**目标：** 修复 Claude Code 启动时从用户级 `~/.claude/settings.json` 重新加载 cc-switch Provider 环境变量，覆盖 UCLI 当前托管档案的问题。

**方案：** UCLI 的 `api_key`、`bearer` 托管档案不加载 Claude 的整个 `user` settings 来源，仅加载 `project,local` 设置来源，并继续通过进程环境传入档案凭据和 Base URL；订阅/系统模式保持 Claude 默认设置来源。UCLI 生成的临时 `--settings` 文件仍负责钩子和安全规则，且不写入任何凭据。该隔离会同时排除用户级 Provider 路由、hooks、permissions 等设置，需在用户文档中明确说明。

**技术栈：** Electron、Node.js ESM、Node test runner、electron-builder。
